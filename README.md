# ⚡ Personal Developer Portfolio

> Современное интерактивное портфолио разработчика для презентации реализованных веб-проектов, стека технологий и оперативной связи.

🔗 **Live Website:** [rummel-dev.vercel.app](https://rummel-dev.vercel.app)

---

## 📌 Ключевые особенности

- 🎯 **Интерактивная витрина проектов:** Структурированные карточки кейсов с модальными окнами, описанием архитектурных решений, списком технологий и прямыми ссылками на Live Demo и GitHub.
- 🎨 **Современный Dark UI:** Чистый интерфейс с выверенной типографикой, плавными микроанимациями и контрастными акцентами.
- 📱 **Полная адаптивность:** Интерфейс оптимизирован под любые устройства — от мобильных экранов до широкоформатных мониторов.
- ⚡ **Высокая производительность:** Архитектура на Next.js App Router с оптимизированными ассетами и мгновенным откликом интерфейса.

---

## 🛠 Технологический стек

- **Framework:** Next.js (App Router, React)
- **Язык:** TypeScript
- **Стилизация:** Tailwind CSS / кастомные стили
- **Иконки:** Lucide React
- **Деплой & Хостинг:** Vercel
